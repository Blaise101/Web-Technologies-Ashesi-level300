Web Technologies Lab 4 – Final Hangman Implementation

Open hangman.html in a web browser.

Final features:
- Random word selection from an array of word/category objects.
- Hidden-word display and A-Z on-page keyboard.
- Correct and incorrect guess handling.
- Official seven Hangman stage images supplied with the lab.
- Mistake counter and score.
- Guessed-letter display.
- New Game button that resets the current round without refreshing the page.
- Physical keyboard support.
- Win and loss detection.
