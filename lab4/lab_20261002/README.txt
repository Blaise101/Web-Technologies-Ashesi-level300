WEB TECHNOLOGIES LAB 4 - INITIAL IMPLEMENTATION

This is the starting implementation for Part 3 of the Hangman lab.

Files:
- hangman.html: page structure
- style.css: appearance/layout
- hangman.js: initial game behavior
- images/: official course Hangman stage images

To run:
1. Keep the folder structure unchanged.
2. Open hangman.html in a browser.
3. Test correct and incorrect letters.
4. For the worksheet, take a screenshot of the browser showing the initial implementation.

Initial implementation scope:
- Fixed word: JAVASCRIPT
- A-Z keyboard generated by JavaScript
- Correct guesses reveal letters
- Wrong guesses advance the official Hangman image
- Six wrong guesses ends the game
- Win/loss message is displayed

This version is intentionally the first working version. Further improvements belong in Part 4.
